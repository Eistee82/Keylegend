## Что он делает

Большинство программ для RGB считает клавиатуру украшением. Keylegend считает её **экраном**.

Каждая клавиша окрашена по тому, что она значит *сейчас*, — и цвет меняется в тот же миг, когда
меняется её значение:

- **Состояние фиксаторов с одного взгляда.** Num Lock, Caps Lock и Scroll Lock показывают своё
  состояние на самой клавише.
- **Цвет по классу символа.** Цифры, строчные буквы, прописные буквы, символы и управляющие
  клавиши получают каждый свой цвет.
- **Удерживайте модификатор — увидите слой.** Нажмите `AltGr`, и гореть останутся только те
  клавиши, на которых действительно есть символ AltGr. Нажмите `Windows` — загорятся сочетания
  Windows, сгруппированные по назначению. То же для `Alt`, `Ctrl` и их комбинаций.
- **Shift и Caps Lock работают сами собой.** Поскольку символ, который выдаёт клавиша,
  запрашивается у Windows в реальном времени, буквы сами переходят из цвета «строчная» в цвет
  «прописная». Цифровой блок перекрашивается в навигацию, когда Num Lock выключен.
- **Игры получают отдельное обращение.** Они распознаются автоматически — в том числе в окне без
  рамки, — и WASD, клавиши вокруг и ряд цифр получают постоянные цвета: во время игры важно, куда
  ложатся руки, а не какую букву набирает клавиша.
- **Профили для приложений, около девяноста в комплекте.** Photoshop, Visual Studio Code, Excel,
  Elden Ring и остальные вступают в силу, как только программа получает фокус, а профиль, в
  котором названа программа, важнее общего игрового профиля. Измените один — и только изменённая
  часть перестанет следовать поставляемой версии, остальное будет улучшаться с новыми выпусками.
- **Возвращает подсветку.** По истечении настраиваемого времени простоя (по умолчанию 60 с)
  Keylegend освобождает клавиатуру, и ваш эффект Chroma Studio снова берёт управление.
- **Одиннадцать языков.** Английский, немецкий, испанский, французский, итальянский,
  нидерландский, польский, португальский, русский, украинский и упрощённый китайский. Интерфейс
  следует языку интерфейса Windows и переключается в настройках. Надписей на клавишах это не
  касается: они следуют вашей клавиатуре, а не меню.

Поскольку значения клавиш берутся из **активной раскладки Windows**, а не из жёсткой таблицы,
Keylegend работает с любой раскладкой — русской, немецкой, американской, Дворака — без изменений.

## Как это устроено

Keylegend спрашивает у Windows, какой символ выдала бы каждая клавиша при текущем состоянии
клавиатуры (`ToUnicodeEx`), выводит из этого символа категорию и отправляет получившуюся карту
цветов в Razer Chroma SDK через его локальный интерфейс REST.

Он намеренно **не** устанавливает глобальный клавиатурный хук. Он читает только *состояние*
модификаторов и фиксаторов; нажатия никогда не перехватываются, не пересылаются и не
записываются. См. [docs/ru/architecture.md](docs/ru/architecture.md).

## Требования

- Windows 10 или 11
- Razer Synapse с работающей службой Chroma SDK
- Подключённая клавиатура Razer Chroma (см. ниже)
- Среда выполнения .NET 10

## Установка

```powershell
winget install Eistee82.Keylegend
```

Самый короткий путь: winget подтянет среду .NET как объявленную зависимость, так что вручную
устанавливать ничего не придётся. Иначе возьмите файл:

[**Скачать последнюю версию.**](https://github.com/Eistee82/Keylegend/releases/latest)

| Файл | Что это |
|---|---|
| `Keylegend-1.0.0-setup.exe` | Устанавливается для текущего пользователя — права администратора не нужны. Пункт в меню «Пуск» и удаление, которое убирает и запись автозапуска. |
| `Keylegend-1.0.0-portable.zip` | Та же программа для распаковки. Папка `devices` должна остаться рядом с исполняемым файлом. |

Ни один файл не подписан, поэтому Windows назовёт издателя неизвестным: сертификат стоит в год
больше, чем есть у этого проекта. В каждом выпуске есть `SHA256SUMS.txt` для проверки загрузки, а
журнал сборки, которая его создала, открыт.

## Поддерживаемые клавиатуры

**Любая клавиатура Razer Chroma.** Нет ни списка, ни файла на каждую модель, потому что Keylegend не
нужно распознавать вашу клавиатуру — он спрашивает. Razer Synapse описывает подключённую: модель по
имени, физическую раскладку числом и клавиши, которые у устройства действительно есть. Собственный
чертёж Razer для этой модели даёт остальное — настоящие размеры клавиш, корпус с колесом и
мультимедийными клавишами и контуры символов, напечатанных на колпачках, на нужном языке.

Единственное, чего чертёж не сообщает, — к какой ячейке матрицы подсветки относится каждая клавиша.
Это константа протокола Chroma, одинаковая на всех моделях, — поэтому и Synapse не нужна таблица по
моделям. Проверено по единственной клавиатуре, откалиброванной вручную: все 105 клавиш совпадают.

`physicalLayout` описывает *форму* клавиатуры, а не язык, на котором вы печатаете. Какой символ даёт
клавиша, выясняется у Windows во время работы, так что немецкая клавиатура работает правильно и при
раскладке US или Dvorak в Windows.

**Требуется Razer Synapse**, установленный и запущенный, с подключённой клавиатурой. Именно там
описана клавиатура и там же лежит её чертёж.

## Сборка и запуск

```bash
git clone https://github.com/Eistee82/Keylegend.git
cd keylegend
dotnet build
dotnet test
```

`Keylegend.exe` (`src/Keylegend.App`) — это вся программа: окно, значок в области уведомлений,
настройки. Единственный ключ, который стоит знать: `--verify` проверяет, несёт ли копия
поставляемые профили и все одиннадцать языков, записывает найденное по указанному после него пути и
отвечает кодом выхода. Именно это скрипт выпуска запускает на упакованной копии.

Настройки находятся в `%APPDATA%\Keylegend\settings.json` и записываются приложением.
