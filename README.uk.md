## Що він робить

Більшість програм для RGB вважає клавіатуру оздобою. Keylegend вважає її **екраном**.

Кожна клавіша забарвлена за тим, що вона означає *зараз*, — і колір змінюється тієї ж миті, коли
змінюється її значення:

- **Стан фіксаторів з одного погляду.** Num Lock, Caps Lock і Scroll Lock показують свій стан на
  самій клавіші.
- **Колір за класом символу.** Цифри, малі літери, великі літери, символи та керувальні клавіші
  дістають кожен свій колір.
- **Утримуйте модифікатор — побачите шар.** Натисніть `AltGr`, і світитимуться лише ті клавіші,
  на яких справді є символ AltGr. Натисніть `Windows` — засвітяться сполучення Windows, згруповані
  за призначенням. Так само для `Alt`, `Ctrl` та їхніх поєднань.
- **Shift і Caps Lock працюють самі собою.** Оскільки символ, який видає клавіша, запитується в
  Windows у реальному часі, літери самі переходять із кольору «мала» в колір «велика». Цифровий
  блок перефарбовується на навігацію, коли Num Lock вимкнено.
- **Ігри мають окреме поводження.** Вони розпізнаються автоматично — зокрема у вікні без рамки, —
  а WASD, клавіші навколо та ряд цифр дістають сталі кольори: під час гри важливо, куди лягають
  руки, а не яку літеру набирає клавіша.
- **Профілі для програм, близько дев'яноста в комплекті.** Photoshop, Visual Studio Code, Excel,
  Elden Ring та інші набувають чинності, щойно програма отримує фокус, а профіль, у якому названо
  програму, важливіший за загальний ігровий профіль. Змініть один — і лише змінена частина
  перестане слідувати постачальній версії, решта поліпшуватиметься з новими випусками.
- **Він повертає підсвічування.** Після налаштовуваного часу простою (типово 60 с) Keylegend
  звільняє клавіатуру, і ваш ефект Chroma Studio знову бере керування.
- **Одинадцять мов.** Англійська, німецька, іспанська, французька, італійська, нідерландська,
  польська, португальська, російська, українська та спрощена китайська. Інтерфейс слідує мові
  інтерфейсу Windows і перемикається в налаштуваннях. Написів на клавішах це не стосується: вони
  слідують вашій клавіатурі, а не меню.

Оскільки значення клавіш беруться з **активної розкладки Windows**, а не з жорсткої таблиці,
Keylegend працює з будь-якою розкладкою — українською, німецькою, американською, Дворака — без
змін.

## Як це влаштовано

Keylegend запитує у Windows, який символ видала б кожна клавіша за поточного стану клавіатури
(`ToUnicodeEx`), виводить із цього символу категорію й надсилає отриману карту кольорів до Razer
Chroma SDK через його локальний інтерфейс REST.

Він навмисно **не** встановлює глобального клавіатурного хука. Він читає лише *стан*
модифікаторів і фіксаторів; натискання ніколи не перехоплюються, не пересилаються й не
записуються. Див. [docs/uk/architecture.md](docs/uk/architecture.md).

## Встановлення

```powershell
winget install Eistee82.Keylegend
```

Найкоротший шлях: winget підтягне середовище .NET як оголошену залежність, тож установлювати
вручну нічого не доведеться. Інакше візьміть файл:

[**Завантажити найновішу версію.**](https://github.com/Eistee82/Keylegend/releases/latest)

| Файл | Що це |
|---|---|
| `Keylegend-1.0.0-setup.exe` | Встановлюється для поточного користувача — права адміністратора не потрібні. Пункт у меню «Пуск» і вилучення, що прибирає й запис автозапуску. |
| `Keylegend-1.0.0-portable.zip` | Та сама програма для розпакування. Тека `devices` має лишитися поруч із виконуваним файлом. |

Жоден файл не підписано, тож Windows назве видавця невідомим: сертифікат коштує на рік більше,
ніж має цей проєкт. У кожному випуску є `SHA256SUMS.txt` для перевірки завантаження, а журнал
збірки, що його створила, відкритий.

## Підтримувані клавіатури

**Будь-яка клавіатура Razer Chroma.** Немає ні списку, ні файлу на кожну модель, бо Keylegend не
потрібно розпізнавати вашу клавіатуру — він запитує. Razer Synapse описує підключену: модель за
назвою, фізичну розкладку числом і клавіші, які пристрій справді має. Власне креслення Razer для цієї
моделі дає решту — справжні розміри клавіш, корпус із коліщатком і мультимедійними клавішами та
контури символів, надрукованих на ковпачках, потрібною мовою.

Єдине, чого креслення не повідомляє, — до якої клітинки матриці підсвітки належить кожна клавіша. Це
стала протоколу Chroma, однакова на всіх моделях, — тому й Synapse не потрібна таблиця за моделями.
Перевірено за єдиною клавіатурою, відкаліброваною вручну: всі 105 клавіш збігаються.

`physicalLayout` описує *форму* клавіатури, а не мову, якою ви друкуєте. Який символ дає клавіша,
з’ясовується у Windows під час роботи, тож німецька клавіатура працює правильно й за розкладки
US або Dvorak у Windows.

**Потрібен Razer Synapse**, установлений і запущений, із підключеною клавіатурою. Саме там описана
клавіатура і там же лежить її креслення.

## Збирання та запуск

```bash
git clone https://github.com/Eistee82/Keylegend.git
cd keylegend
dotnet build
dotnet test
```

`Keylegend.exe` (`src/Keylegend.App`) — це вся програма: вікно, значок в області повідомлень,
налаштування. Єдиний ключ, який варто знати: `--verify` перевіряє, чи несе копія постачальні
профілі й усі одинадцять мов, записує знайдене за вказаним після нього шляхом і відповідає кодом
виходу. Саме це скрипт випуску запускає на запакованій копії.

Налаштування лежать у `%APPDATA%\Keylegend\settings.json` і записуються застосунком.
